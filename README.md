The website has been designed to adapt to different screen sizes.

It includes responsive layouts for:

* 💻 Desktop

## 🚀 Deployment

This website is deployed using **GitHub Pages**.

To deploy a similar static website:

1. Create a repository on GitHub.
2. Upload your HTML, CSS, and image files.
3. Go to **Settings → Pages**.
4. Select the appropriate branch.
5. Save the settings.
6. GitHub will generate a live website URL.
